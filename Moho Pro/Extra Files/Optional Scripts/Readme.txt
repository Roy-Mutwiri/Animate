The scripts in this folder have either been provided by third parties, or have been
superseded by features built into the main application. If you have used these scripts
in the past and want to continue using them, you are welcome to reinstall them in your
user support folder.

The Command Line Scripts folder has two example scripts that can be called from the
command line. These are for advanced users - the purpose of command line scripts is
typically to automate the creation or modification of multiple files in a project that
makes use of many Moho files.

On Windows, it can be helpful to show console output when running command line scripts.
To do this, run a command line script with the -attachconsole or -console options.
The first one prints info out to the command line console you launched Moho from.
The second one opens a new console window just for Moho.

Moho.exe -attachconsole MyScriptFile.lua

Moho.exe -console MyScriptFile.lua
