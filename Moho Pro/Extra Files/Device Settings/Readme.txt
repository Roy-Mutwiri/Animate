Here we have settings files for a couple hardware devices that can make it easier to use Moho without a keyboard.
These are totally optional, but if you have one, try out these presets to get your device set up for Moho.

To use any of these, you will need the corresponding device's driver software installed.
Then, go into the device management software and install a new application preset.
